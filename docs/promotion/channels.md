# 推广渠道台账

本文件记录 Stoma 中文推广的投放渠道、投放状态与归因口径。

**语言**：全部渠道的语言均为 `zh` —— 本轮推广限于中文技术社区（R-8）。

---

## 字段说明

| 字段 | 含义 |
|------|------|
| **渠道标识** | 渠道的稳定短名 |
| **平台** | 投放所在的网站 |
| **语言** | 恒为 `zh` |
| **内容定位** | 该渠道投放内容的切入角度与形态 |
| **与社区既有话题的关联说明** | 说明投放内容如何接上该社区本来就在讨论的话题（FR-011 要求） |
| **投放状态** | `未投放` / `已投放` / `已收录` |
| **投放时间** | 首次投放日期；未投放时留空 |
| **是否可被社区正常访问** | 投放后该链接是否无需登录即可访问 |
| **非作者互动数** | 30 天内来自非作者的实质性互动次数（观测用，不设阈值） |
| **referrer 域名** | 从该渠道点进来时在流量统计中出现的来源域名（**不采集** —— GitHub 流量指标需 token） |
| ~~**落地页路径**~~ | ~~渠道专属落地页在本仓的路径~~ —— **已取消**（2026-11-20） |

## 归因口径

**本期不做渠道归因**（2026-11-20 规格所有者决定）。原有的两条归因路径均已取消：

1. ~~**渠道专属落地页**~~ —— GitHub 流量指标需 token 且只覆盖滚动 14 天窗口，R-7 已决定不采集；
   落地页文件在 GitHub 上是死链，无法承担归因作用。帖子直接指向 GitHub 仓库。
2. ~~**Discussions 的渠道自述**~~ —— 不在 README 设「从何处得知」引导，也不做反馈章节。

**替代做法**：由维护者在本文件手动登记投放记录与社区反馈 —— 本期只有 TesterHome 一个渠道，
来源可从帖子所在位置与读者反馈直接辨认。
